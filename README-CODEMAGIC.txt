CICCIO'S SUNMI - BUILD WEB CON CODEMAGIC

1. Carica TUTTI i file e le cartelle di questo progetto nella root della repository GitHub ciccios-sunmi.
2. In Codemagic aggiungi la repository GitHub.
3. Codemagic rilevera' il file codemagic.yaml.
4. Avvia il workflow "Ciccios SUNMI APK".
5. A build completata, apri Artifacts e scarica app-debug.apk.
6. Installa l'APK sul SUNMI V2.

Prima configurazione app:
- URL API: l'endpoint mostrato dal plugin WordPress Ciccio's SUNMI Orders.
- Token dispositivo: il token mostrato nelle impostazioni dello stesso plugin.

L'APK debug e' firmato automaticamente ed e' installabile per il test sul terminale.
